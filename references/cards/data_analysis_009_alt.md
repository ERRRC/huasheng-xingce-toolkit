## 解题步骤 (`steps`)

- 1. 本期比重 = 部分 / 整体；多部分比重 = 部分和或差 / 整体
- 2. 基期比重 = 现期比重 * (1 + R整体) / (1 + R部分)
- 3. 隔级比重（大、中、小嵌套）：小/大 = (小/中) * (中/大)
- 4. 比重趋势判断（秒杀）：直接找部分和整体的增长率比较。部分增长率 > 整体增长率，比重变大；部分增长率 < 整体增长率，比重变小
- 5. 比重趋势逆运用：已知比重变化情况，反推增长率的大小关系

## 公式 (`formulas`)

- 比重 = 部分 / 整体
- 基期比重 = (本期部分/本期整体) * ((1+R整体)/(1+R部分))

## 示例 (`examples`)

-
  - context：中部地区快递业务量比重上升0.5个百分点，全国增速为26%，求中部地区增速
  - action：比重上升说明中部增速大于全国增速（>26%）

## 易错点 (`pitfalls`)

- 基期比重公式中分母的 (1+R整体) 和 (1+R部分) 位置颠倒
- 混淆部分和整体的对应关系
