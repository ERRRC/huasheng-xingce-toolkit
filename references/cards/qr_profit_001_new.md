## 解题步骤 (`steps`)

- 基础利润问题：利用单日利润 = 单件利润 × 数量，若销量只有比例变动，可赋值调整前销量为100，根据前后总利润相等列方程求解。
- 增长率相关利润问题：利用销量 = 总利润 / 单个利润，若已知比值增长率，应用公式：销量变化率 R = (总利润增长率 - 单个利润增长率) / (1 + 单个利润增长率)。
- 分批销售利润问题：第一部分分销收入 + 第二部分分销收入 = 总销售收入，设未知数（如降价多少）列方程求解。

## 公式 (`formulas`)

- 售价 = 成本 (即进价) + 利润
- 总成本 / 总利润 / 总销售金额 = 单个成本 / 单个利润 / 单个售价 × 数量
- 折扣：指实际售价为原定价的几成（折扣和成本无关，和原定价有关；折扣率与折扣正相反，打三折即折扣率为70%）
- 利润率 = 利润 / 成本 （如成本100，利润30，利润率30%）
- 销量变化率 R = (R1 - R2) / (1 + R2) （其中R1为总利润增长率，R2为单件利润增长率）

## 示例 (`examples`)

-
  - context：【例】(2020北京) 某商品成本为200元，售价为292元，将售价调整为268元，预计日销量将上涨15%。现欲降低成本以保持降价前的单日利润，则单件产品的生产成本至少需要降低多少：
  - action：【解】单日利润=单利*数量。设现在单利为x，赋值调整前销量为100。调整前单利*调整前销量 = 现在单利*现在销量：(292-200)*100 = x*100*(1+15%)，解得x=80。则现在成本=268-80=188。成本降低：(188-200)/200 = -6%。
-
  - context：【例】(2019联考) 定价降低10%，每台产品利润提升10%，2017年全年总利润较2016年增加了21%。2017年的销量比2016年：
  - action：【解】销量=总利润/单利润，符合比值增长率R1=21%，R2=10%。销量R = (R1-R2)/(1+R2) = (21-10)/(1+10) = 10%。
-
  - context：【例】(2017联考) 购进500件衬衫每件80元，以每件120元销售了400件，要达到盈利45%的预期目标，剩下的衬衫最多可以降价：
  - action：【解】设降价后售价减去的折扣为x，用收入列式：120*400 + (120 - x)*(500 - 400) = 80*500*(1 + 45%)，解得x=20。

## 易错点 (`pitfalls`)

- 混淆售价与定价（售价是最终出售的，定价是最初的）
- 混淆折扣（售价占定价比例）与折扣率（降价占定价比例）
- 计算利润率时分母用错（应为成本而不是售价）
