## 解题步骤 (`steps`)

- 根据题意设定未知数（通常设变动次数或变动量为x）。
- 列出总收入或目标乘积的表达式：y = (基础单价 + 单位变动×x) × (基础销量 - 单位变动×x)。
- 方法一（中点最值）：令 y=0 得到两个根 x_a 和 x_b，当 x = (x_a + x_b) / 2 时，y取最大值。
- 方法二（均值定理）：整理表达式提取系数，使括号内两项系数成互为相反数。当两项之和为定值时，令两项相等，解出x即为最优解。
- 方法三（公式法）：展开为 ax^2+bx+c，利用对称轴 x = -b / (2a) 求最值。

## 公式 (`formulas`)

- 函数形式：y = ax^2 + bx + c (当 x = -b/2a 时取最值)
- 中点最值特性：令 y=0 求交点 x_a, x_b，当 x = (x_a + x_b) / 2 时y取最值
- 均值定理：a+b为定值，当 a=b 时，ab最大

## 示例 (`examples`)

-
  - context：【例】(2018联考) 某苗木公司准备出售一批苗木，如果每株以4元出售，可卖出20万株，若苗木单价每提高0.4元，就会少卖10000株。问在最佳定价的情况下，该公司最大收入是多少万元？
  - action：【解】设提高x个0.4元，收入为y，y = (4 + 0.4x)(20 - x)。令y=0，得x1=-10, x2=20。取中点x = (-10+20)/2 = 5时取最高点，将x=5代入，解得y=90。【均值定理】将y整理为 y = 0.4(10+x)(20-x)，此时 (10+x) + (20-x) = 30为定值，当 10+x = 20-x 即 x=5 时乘积最大，y取最大值。
