## 推理策略 (`reasoning_policy`)

- core_logic：找到存在的矛盾关系（必然一真一假）。结合真假的数量确定矛盾以外的其他命题的真假情况，从而得出确定事实，再反推矛盾双方的真假。
- detailed_policy：1. 找矛盾；2. 看其余（若只有一真，其余必假；若只有一假，其余必真）；3. 根据确定的其余命题得出事实，再判断矛盾双方。

## 解题步骤 (`steps`)

- 1. 找出题干中互为矛盾的两个命题（如 A 和 非A，所有 和 有些不）。
- 2. 根据题干限定的真假总数，抛开矛盾命题，断定其余命题的真假。
- 3. 由其余命题的真假推导出确定的事实。
- 4. （如需要）将事实代入矛盾命题，判定谁真谁假。
