## 解题步骤 (`steps`)

- 1. 先求出部分增长率(Ra) - 整体增长率(Rb)，根据符号判断比重是上升(>0)还是下降(<0)，排除两个选项
- 2. 【比重差秒杀技】：一般来说，(基期部分/本期整体) < 1，因此必有 |比重差| < |Ra - Rb| (增速差)，选小于增速差的那个选项
- 3. 【比值差不可秒杀】：比值差的分子分母单位不同，a/B 并不一定小于1，所以不能用增速差秒杀
- 4. 若不能秒杀，代入公式计算：比重差/比值差 = (a / B) * (Ra - Rb) / (1 + Ra)。计算基期部分(a/(1+Ra))时，使用假设分配法第一步即可，允许一定误差

## 公式 (`formulas`)

- 比重差 = 本期比重 - 基期比重 = (a / B) * (Ra - Rb) / (1 + Ra)
- 比值差 = (a / B) * (Ra - Rb) / (1 + Ra)

## 示例 (`examples`)

-
  - context：中石化供气量同比增速8.8%，全市供气量同比增速3.83%，求中石化比重上升了多少个百分点
  - action：第一步：8.8% > 3.83%，比重上升；第二步：比重差 < |8.8% - 3.83%| = 4.97%，若选项中只有一个小于4.97%，直接秒杀。

## 易错点 (`pitfalls`)

- 将比值差（如人均收入的差值，带具体单位）错误地使用比重差秒杀技（|差|<|增速差|）
- 混淆比值差（有单位）和比值增长率（百分号%）的公式

## 避免事项 (`forbidden`)

- 直接计算两期比重再做差求结果（计算量过大）

## 原卡输出约束 (`output_constraints`)

- 选出正确的百分点差值或具体单位差值
