## 解题步骤 (`steps`)

- 1. 观察选项是否全面且具体。若是，直接把选项代入题干中验证。
- 2. 如果代入不便，选择一个命题进行假设（通常从最有可能导致冲突的命题开始，如复合命题）。
- 3. 根据假设推导，若产生矛盾，说明假设不成立，取其反面即为真。
- 4. 结合确定的真实情况继续推导。
